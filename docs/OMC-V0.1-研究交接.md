## 任务 A：统一研究模型

### A.1 形式化定义

**环境.** E = (S, A, T, Ω, O, ρ₀, R, C_env, TaskGen)

- S 状态空间，A 动作空间，T(s′|s,a) 转移，Ω 观测空间，O(o|s) 观测函数，ρ₀ 初始分布。
- R：任务成功判定（奖励 ≠ 研究目标，见 A.3-8）。
- C_env：资源动态（可采集/消耗的资源、时变条件）。
- TaskGen：任务生成器，任务分布 P_task，支持分布外采样。

**智能体.** Aᵢ = (Gᵢ, Bᵢ, Mᵢ, Kᵢ, πᵢ, Vᵢ)

（相对原定义的修改：删去 Sᵢ。当前内部信念/上下文是运行态变量，不是身份定义的一部分。）

- Gᵢ（Genome）：本代内不可变的 {架构， 学习规则， 先验， 超参数}。**操作判据：代际是否重置**——重置的归 G，继承的归 K/M。
- Bᵢ（Body）：（传感器， 执行器， 动作空间）。V0.1 中全体同构，为占位符。
- Mᵢ（Memory）：情景记忆 = {(t, s, a, o, r, 上下文)} 的追加日志 + 索引。**只记录"发生过什么"，不做概括**。
- Kᵢ（Knowledge）：个人显式知识 = 知识记录集合。**与 M 的区别：K 的每条记录必须可执行（能产生预测/行动）且可证伪（带有明确的反例条件）。**
- πᵢ（Policy）：π(a|s;θ) 行动策略。探索不单独设 πₑ（见 A.3-1）。
- Vᵢ（Values）：（目标生成器， 偏好序， 探索倾向）。V₀ 由设计者给定；目标生成本身是研究对象。

**知识记录（个人 Kᵢ 与文明 Kⱼ 共用同一 schema）.**

k = (id, 命题 p, 表达形式, 证据 E, 适用条件 Cond, 来源 Prov, 置信 c, 状态 σ, 反例 X, 未解问题 Q)

- 表达形式 ∈ {可执行程序 / 符号表达式 / 预测模型 / 技能策略}。V0.1 不用自然语言假说。
- σ ∈ {候选， 已复现， 已证伪， 已取代}。状态机：候选 →（独立复现）→ 已复现 →（反例出现）→ 已证伪/已取代。
- **这是"知识库不退化为 RAG"的设计答案**：RAG 存文本，OMC-KB 存可执行的、可证伪的记录；检索依据是对当前任务的预测效用，而非文本相似度。

**文明.** Cⱼ = (Pⱼ, Kⱼ, Iⱼ, Rⱼ, Πⱼ)

（相对原定义的修改：删去单体 Gⱼ/Vⱼ。文明没有单一 genome/value，只有成员分布与制度。）

- Pⱼ 成员集合；Kⱼ 文明知识库（记录集合 + 晋升规则）；Iⱼ 制度 = {通信协议， 知识晋升/准入规则， 资源分配规则， 成员加入/退出/分裂规则}；Rⱼ 资源预算；Πⱼ 成员 G 的分布（"传统" = 分布，不是单点）。

**信息流.** λ 不是标量，而是一个协议：λ = (可见性 v, 带宽 b, 推/拉模式)。

- V0.1 操作定义：每轮每智能体可从其他文明公共 KB 拉取 ≤ b 条"已复现"记录；λ=0 ⟺ b=0；λ=1 ⟺ b 不限（仍受通信预算约束）。
- **v 和 b 的效应必须分别报告**，不可混为一个参数（原提示词第四部分自己指出了这一点）。

**资源约束.** 总预算 B = (B_compute, B_interact, B_comm)：计算（FLOPs/求解器调用）、环境交互步数、通信条目数。

- **所有对照组必须在总预算相等下比较**（9.2 的核心要求，无例外）。
- 成本统一记账：C(t) = w₁·compute + w₂·interact + w₃·comm，权重公开。

**指标（V0.1 操作定义）.**

- P(t)：保留测试任务成功率/误差。测试集三分：分布内 / 分布外（新函数族）/ 组合任务。
- K(t)：状态=已复现的**去重**记录数。去重规则：两条记录在探测集上预测一致则合并（预测等价类）。
- L(θ*)：首次达到能力阈值 θ* 所需的总成本 C。**θ* 必须预注册**。
- N(t)：单位成本内新增"解决此前失败任务"的已复现记录数。区分候选新颖性 vs 验证后创新。
- D(t)：多维，**双侧**（坍缩 vs 极化，见任务 E/简报）——行为（查询模式成对距离）、假设（符号空间分布熵/分歧度）、学习曲线（达阈值时间分布）、文明间分化度（Fst 类比）。**不直接用神经网络参数距离**。
- T(t)：新任务族上的迁移增益（相对无继承基线）。
- R(t)：知识记录独立复现成功率。
- C(t)：累计总成本。

**代际更新.** 第 g 代 → g+1 代：

(Kᶜ_{g+1}, {Gᵢ^{g+1}}) = Inherit(按选择规则取 Kᶜ_g 的已复现子集， Mutate({Gᵢ^g}))

- Inheritance 只传 K（已复现记录）+ G 分布；**M（情景记忆）重置**——这就是"复制模型 ≠ 复制智能体"的操作定义：被复制的是参数与知识，不是经历。
- π 从继承的 K 热启动（初始候选集 = 继承的已复现假设 + 扰动）。
- Mutation：超参数 / 探索规则 / 记忆组织参数的受约束变异。V0.1 不做代码自修改。

**学习算法变异.** μ: G → G′，选择压力 = 下一代在固定评估套件上的学习成本 L。

- 诚实标注：这是设计者给定的元目标。"开放性"在此被边界化（见 A.3-9）。

### A.2 因果链条（每条箭头 = 一个可消融机制）

1. 经验 →（概括 + 独立复现）→ 知识记录
2. 知识记录 →（晋升规则）→ 文明 KB
3. 文明 KB →（拉取 / 教学）→ 他人先验 → 学习成本变化
4. 知识记录 →（复现选择）→ 代际继承 → 新一代初始 K
5. G 变异 →（选择压力 = L）→ 下一代 G 分布

### A.3 含糊、重复、矛盾点（诚实清单）

1. **πₑ 独立存在性存疑**。探索策略 vs 行动策略的二分是概念便利；实现中探索常内嵌于 π（内在动机 / Thompson 采样 / query-by-committee）。若保留二分，必须给出 πₑ 独立于 πₐ 的**可观测判据**，否则合并。V0.1 建议：先不拆。
2. **K 与 M 的边界未定义**。"概括"发生的确切条件缺失。补上：M→K 晋升需要 (a) 可执行表达 (b) 至少一次独立复现 (c) 明确适用条件。没有这条管线，"知识积累"只是口号。
3. **λ 欠定**（见上）：拆成（可见性， 带宽， 推/拉模式）。
4. **G vs K 混淆**。元学习到的先验算 G 还是 K？判据：代际是否重置。重置 ⟹ G 的一部分；继承 ⟹ K。
5. **三过程区分在实现中坍缩**。文化进化（知识的选择性传播）本身就是一种进化算法；"架构进化"在 V0.1 = 超参数搜索 / PBT。概念三分法可保留，但实现上诚实标注。
6. **Sᵢ 冗余**。内部运行态不应出现在身份定义中。
7. **文明定义中的单体 Gⱼ/Vⱼ**。文明没有单一 genome；改为成员分布 Πⱼ 与制度 Iⱼ。
8. **矛盾：反 Goodhart vs 指标驱动**。"不最大化预定基准"与"H1–H8 全用任务表现评估"直接冲突。解决：评估套件必须包含**生成时未见的任务族**（开放性的操作定义 = 在评估设计者也未预见的任务上的表现），并报告 Pareto 前沿而非单分数 F。
9. **"学习方式改进"的递归无锚点**。若学习规则的变异由固定元目标（L 最小化）选择，则"开放性"只是修辞。诚实版本：V0.1 研究的是**有界开放性**（bounded open-endedness）——任务族内开放，元目标上封闭。真正的无界开放（元目标本身可变）是 V2+ 的问题，不要在 V0.1 声称。

## 任务 B：最脆弱的三个假设

### B1. H8：系统能自主产生"有价值"的新问题

- **可能成立**：不确定性驱动的实验设计确实能提出人类没预设的查询；科学史中新问题常来自反常观测，而反常可形式化为预测误差突增。
- **可能失败**："有价值"无定义——随机采样也能生成大量"新问题"，价值只能事后由下游学习增益定义，有循环论证风险。最可能结果：智能体提出的问题 ≈ 不确定性采样的结果，"自主问题生成"模块无增量贡献。
- **最简单的替代解释**：问题生成 = 在当前信念下期望信息增益最大的查询；任何主动学习基线都能做到。
- **最低成本证伪实验**：三组对比——(a) 智能体自主问题生成 (b) 纯不确定性采样 (c) 随机查询；测量单位成本带来的验证后知识增量 ΔK/C。若 (a) ≯ (b)，H8 在 V0.1 意义下不成立，"问题生成器"只是主动学习的改名。
- **改变方向的结果**：若 (a) 持续显著优于 (b)，说明存在超越不确定性采样的"问题价值"结构（跨任务迁移价值、反例导向等），"问题生成"值得立为独立研究对象；反之降级为工程模块。
- 外部工具：Autonomous Science Bench（discovery gate + learning gate 双门槛，144 试验中 31 通过）可作为 V0.2 评估 H8 的外部仪器（引自 2026-10-16 简报，原文未独立核实）。

### B2. H3：跨文明信息流 λ "存在可测量的关系"

- **可能成立**：共享降低重复探索；隔离保护多样性；直觉上存在权衡。
- **可能失败**：原命题**几乎不可证伪**——"存在可测量的关系"在任何效应（包括零效应）下都成立。更深风险是混淆：λ 同时改变信息量、有效数据量、通信开销；观测效应可能完全由"总知识访问量"驱动，与文明拓扑无关。
- **最简单的替代解释**：起作用的是**总知识预算**（每智能体能读多少条有效记录），不是跨文明拓扑。单文明大 KB + 限额拉取可复现多文明的全部效果。
- **最低成本证伪实验**：固定**总知识访问预算**（每智能体每轮可读记录数恒定），只改变拓扑：A=单文明共享池，B=10 文明 λ=1，C=10 文明 λ=0.1。若 A≈B≈C，则"多文明/λ"是冗余结构，真变量是访问预算——直接挑战第四部分的核心理论主张。
- **改变方向的结果**：若预算匹配下拓扑仍有显著效应（例如 λ 中间值在 D 不坍缩前提下 N 最高），则多文明结构是真实机制，制度 Iⱼ 的设计成为核心；反之项目收缩为"单文明知识库 + 访问控制"研究，砍掉大部分文明系统复杂度（呼应 9.4）。
- 方法论补强（引自 2026-10-16 简报）：23 模型辩论研究在**匹配生成预算**下否定了"多样性驱动增益"，增益实为集成采样伪影，且 persona 提示降低准确率。因此一切"社会结构增益"声明必须先过预算匹配对照，否则不可信。

### B3. H6：学习策略受控变异产生"超出固定策略"的改进

- **可能成立**：PBT/超参数进化在 RL 中确实有效；不同任务阶段可能需要不同探索强度。
- **可能失败**：V0.1 的"变异"（超参数扰动）本质是**调参**，改进可被"固定最优配置 + 相同总预算"复现；"进化发现新学习算法"的强主张与实验检验的弱版本之间存在偷换。
- **最简单的替代解释**：观测改进 = 在更大配置空间搜索的红利，而非"进化"机制本身。
- **最低成本证伪实验**：总预算匹配下对比——(a) 变异种群 (b) 固定配置（取自 (a) 最终分布的众数，从头重跑） (c) 随机搜索同等配置数。若 (a) ≯ (b)，"代际变异"无增量价值；直接威胁 Evolution 模块的存在必要性。
- **改变方向的结果**：若 (a) 优于 (b) **且优势可迁移到新任务族**（非过拟合训练分布），则"学习策略的可进化性"是真问题；反之 Evolution 降级为离线超参数搜索。

（注：H1 是整座大厦的地基，应最优先检验；H2 相对稳健——来源追踪 + 独立验证是科学社会学常识机制，证伪它需要证明"验证无用"，先验概率低。）

## 任务 C：OMC-V0.1 最小可行实验（LawLab）

### 设计决策：为什么选符号规律发现环境，而非 gridworld

1. 知识 = 符号表达式 / 可执行程序，天然可执行、可证伪、可计件——Q4（有效知识定义）、Q10（新颖性）直接可操作化。
2. 验证是机械的（保留查询点上预测），评估独立性天然成立。
3. 实验设计 = 主动学习，有成熟基线可对比（9.2 的替代解释事先备好）。
4. 零物理仿真成本；智能体可**程序化**实现（符号回归 + 贝叶斯探索），**不需要每智能体一个 LLM**——100 智能体 × 多种子单机可跑。
5. 直接实例化"科学发现循环"，这是 OMC 区别于普通 MARL 的独特主张。

**诚实声明的代价**：LawLab 测不到具身、连续控制、社会博弈——那是 V0.2（gridworld crafting）的内容。V0.1 只回答一个问题：**知识的社会积累与代际继承能否降低学习成本而不坍缩多样性？**

### C.1 环境

- 目标函数族 F：由文法生成的 f: ℝ²→ℝ（三类"任务族"：多项式 / 三角组合 / 分段函数；类间为分布外）。
- 交互：智能体选择查询点 x（成本 c_q），观测 y = f(x) + ε。
- 每代固定查询预算 B_q；任务 = 在保留测试点集上达到预测误差 MSE ≤ θ*。
- 环境版本、文法、噪声、种子全部记录。

### C.2 智能体（程序化，非 LLM）

- 信念：候选假设集（特征库上的稀疏回归，默认求解器；GP 为消融备选）+ 每个假设的证据（查询点、残差）。
- 探索：query-by-committee（在候选分歧最大的点查询）/ 期望信息增益 / 不确定性采样（超参数可变异）。
- 知识记录示例：k = (id=042, "y ≈ 2.1x₁² − 0.5·sin(x₂)", 证据={37 查询， 残差}, 条件="x∈[−2,2]², 多项式+三角族", 来源=(agent 7, gen 2, 父记录 011), 置信=0.82, 状态=已复现×3, 反例=∅, 未解="分段边界处误差大")。
- **晋升规则（H2 的操作化）**：候选 → 需**另一智能体用全新查询独立复现**（MSE 达标）→ 已复现。只有"已复现"计入 K(t)、可被跨文明拉取、可代际继承。

### C.3 文明与信息流

- 10 文明 × 10 智能体（先以 3 文明 × 4 智能体做冒烟测试）。
- 文明内 KB 完全可见；跨文明每轮每智能体可拉取 ≤ b 条已复现记录，测试 b ∈ {0, 1, 5, ∞}。
- **总知识访问预算匹配**：对照组间"可读记录总数"一致，分离拓扑效应（任务 B 的 B2 实验）。

### C.4 对照组

- **A**：独立学习（无 KB）。
- **B**：单文明大 KB（100 智能体共享，拉取配额 = C 组总配额）。
- **B+**：B 去掉来源追踪与复现要求（纯共享池）→ 检验 H2。
- **C**：多文明 + λ（b）梯度。
- **Null-Civ**（任务 E）：中央经验回放 + 共享假设榜，无文明结构。
- **Oracle**：给定真实函数族的上界对照（分离"求解器瓶颈"与"社会机制效应"）。
- **A×n**：A 组配 n 倍独立采样预算（杀死"集成采样伪影"，引自简报的辩论研究教训）。

### C.5 评价指标与预注册

- P：保留测试点 MSE（分布内 / 新函数族 / 组合三分）。
- K：已复现去重记录数（预测等价类去重）。
- L：首次达 MSE ≤ θ* 的总成本（查询×c_q + 求解器调用×c_s），报告中位数 + IQR。
- N：每千成本内新增"解决此前失败任务"的已复现记录数。
- D（双侧）：成对预测分歧度、假设族分布熵、文明间分化度（Fst 类比）、查询模式多样性。**同时检测坍缩（全体收敛同一假设）与极化（文明锁定互不兼容假设、跨文明采用率≈0）**。
- T：新函数族迁移增益（相对 A）。
- R：复现成功率。C：总成本记账。
- **预注册**（实验前写死）：θ*、B_q、种子表、成功判据，例如"B 组达 θ* 的中位成本显著低于 A 组（20 种子，置换检验 p<0.05），且 B 组终期 D ≥ A 组终期 D 的 80%"。

### C.6 计算预算与统计

- 冒烟：3 文明 × 4 智能体 × 3 种子，单机分钟级。
- 正式：100 智能体 × 10 文明 × ≥20 种子；预算匹配是硬约束；报告均值 + 95% bootstrap CI + 置换检验；失败种子完整保留并分析。

### C.7 预期失败模式

1. 共享无增益：B≈A（任务太简单，或知识表达不匹配接收方信念）。
2. 同质化：B/C 的 D 坍缩（探索停滞）——预设熔断：D 跌破阈值则标记"机制有害"。
3. 极化：C 组文明锁定不兼容假设、跨文明采用率≈0（λ 过低的另一侧失败）。
4. 验证瓶颈：复现要求过严导致 K 停滞（晋升规则太保守）。
5. 求解器瓶颈：效应被符号回归能力掩盖（用 Oracle 组识别）。

### C.8 完成判定

V0.1 完成的充要条件：**对 Q1（共享知识在预算匹配下是否降低 L）给出统计显著的肯定或否定回答**，附带 D 双侧变化报告；或任一核心假设被干净证伪。**不以"系统跑起来"为完成标准**（呼应 8.10）。

## 任务 D：工程实现计划（9 步）

每步：交付物 → 测试 → 完成标准。铁律：**第 1–3 步先跑通最小闭环，再做 4–9**（呼应 8.8/8.9）。

1. **最小环境**：`environment/lawlab.py`（文法、查询 API、成本记账、种子管理）。测试：种子确定性、预算超支抛错。标准：随机策略基线可跑出学习曲线。
2. **单个 Agent**：`agents/`（信念更新、稀疏回归求解器、探索策略）。测试：单函数族 50 查询内 MSE 达标。标准：孤立智能体学习曲线单调、可复现。
3. **独立学习基线**：`experiments/run_baseline.py` + append-only JSONL 日志（每步的查询、假设、误差、成本）。标准：A 组 20 种子跑通，产出 P/L 基线。
4. **共享记忆基线**：`culture/`（记录 schema、KB、发布/拉取、晋升状态机、来源追踪）。测试：注入一条错误记录，验证它永为候选、无法晋升。标准：B 组与 B+ 组可跑（两者对比即 H2 检验）。
5. **多文明通信**：`civilization/`（文明划分、跨文明拉取配额、λ 参数化）。测试：λ=0 时跨文明零泄漏（断言）；λ=∞ 时等价于 B 组（一致性检验）。标准：C 组 λ 梯度可跑。
6. **指标记录**：`evaluation/metrics.py`（P/K/L/N/D/T/R/C 纯函数 + 合成日志单元测试）。标准：所有指标在已知答案的合成数据上测试通过。
7. **实验脚本**：`experiments/configs/*.yaml`（预注册参数：θ*、预算、种子表、成功判据）+ 断点续跑。标准：杀掉重跑结果 bit-identical（除 wall-clock）。
8. **消融测试**：`experiments/ablations.py`（一键开关：验证 / 来源追踪 / 文明结构 / 问题生成器）。标准：每个消融恰好改变一个机制（代码审查确认）。
9. **结果分析**：`evaluation/reporting.py`（CI、置换检验、预注册判据自动判定、失败案例导出）。标准：输出"判决书"——每个预注册问题回答成立 / 不成立 / 证据不足。

估计工作量：核心 ~1500–2500 行 Python + 实验脚本。工程铁律：配置驱动、种子一切、日志 append-only、不先搭大框架。

## 任务 E：更优方案与直接批评

### E.1 三个"如果我是 PI 会改"的决定

**1. 把"文明"降级为待检验的假设，而非架构起点。**
原设计把多文明当一等公民，但 B2 已指出它可能是冗余复杂度。更优顺序：先证明"验证过的共享 KB"有效（B 组），再问"需不需要文明结构"（Null-Civ 消融）。**默认假设应该是"不需要"，由证据推翻**——这是 9.4 的直接应用。预计砍掉第一阶段 60% 的制度/经济/分裂重组代码。

**2. 用"记录级选择"替代"文明级进化"作为第一进化机制。**
真正的进化单元在 V0.1 不是文明，而是**知识记录**：变异（智能体提出新假设/修正）→ 选择（独立复现 + 预测效用）→ 继承（KB 保留）。这是进化认识论（Campbell: blind variation + selective retention）的直接实例，比"文明进化"更锋利、更易测量。文明只是记录选择的**种群结构**（岛屿模型 island model），λ 就是迁移率——于是第四部分可重写为群体遗传学语言，H3/H4 直接对应"迁移率 vs 种群分化"的经典权衡，有现成数学可用（Fst 类比、有效种群大小、迁移-选择平衡）。这不是文学修辞，是可借用的形式工具。

**3. 把 H8 的"问题生成"重构为"实验设计"，用因果增益定义价值。**
"有价值的新问题"不可操作；"预算内最大化验证后知识增益的查询策略"可操作。价值的因果定义：ablate 掉该问题生成器，ΔK/C 下降多少。先做到这一步，再谈"自主科学发现"。

### E.2 一个更便宜的"第零实验"（V0.1 之前跑）

**2-Agent 熔断器**：2 个智能体，1 个共享 KB（带复现晋升），vs 2 个孤立；同一函数族；预算匹配。若连 2-Agent 都看不到 L 的显著下降，100-Agent 的文明实验只会烧钱。1–2 天可完成，是整个项目的**熔断器**，建议最先跑。

### E.3 对原提示词的三个直接批评

1. **"开放式"与"可评估"存在根本张力，原提示词回避了它。** H1–H8 全在设计者定义的任务分布上评估，V0.1 能证明的最多是"有界开放性"。诚实路线图：V0.1 有界开放（任务族内）→ V0.2 评估者未见的任务族（真分布外）→ V1.0+ 元目标可变。不要在 V0.1 声称研究"开放式"，那会稀释证伪力度。
2. **πₑ 的独立性可能是伪问题。** 如果探索只是"信息价值驱动的行动"，强行拆出 πₑ 会制造不存在的模块边界。建议先不拆，用内在动机统一实现；只有当"纯利用策略 + 独立探索模块"显著优于统一策略时，才承认二分。
3. **100 智能体 / 10 文明的初始规模缺乏依据。** 规模是实验变量，不是启动参数。从 2-Agent 熔断器开始按需放大——"小规模先验证机制"是 6.1 自己写的，应彻底执行。

### E.4 必须保留的原创性（三点）

- "文明可以继承，真理不能继承" → 落实为**晋升状态机 + 独立复现**，KB 设计的灵魂。
- "学习算法本身成为演化对象" → 收敛为**超参数/探索策略的代际变异 + 选择压力 = 学习成本 L**，诚实且可测。
- "多样性来自生态位而非多样性奖励" → LawLab 中落实为**异质函数族 / 异质查询成本 / 异质噪声**，而非 D 奖励项。

### E.5 来自今日简报的方法论补强

- **预算匹配是生死线**：23 模型辩论研究证明，未匹配预算的"社会结构增益"很可能是集成采样伪影。OMC 所有组间比较必须匹配总预算，否则结论无效。
- **多样性是双侧控制问题**：坍缩（同质化）与极化（文明锁定、互不采用）都是失败。λ 的真正研究问题不是"倒 U 型"，而是**约束优化**：在 D_within ≥ 阈值、跨文明采用率 > 0 的约束下最大化验证新颖率 N。
